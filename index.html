AI work

AI-assisted curriculum work

How I use AI to write and review curriculum faster, without lowering accuracy.

  1. Chapter-authoring skillsClaude

    Built reusable Claude skills that draft full textbook chapters from a curriculum source of truth: student lessons, teacher notes, worksheets and answer keys. Companion skills write chapter reviews and chapter refreshers, so every chapter starts from the same scope and style.

  2. AI-built review toolsClaude Code

    Used AI to build browser-based review panels and side-by-side diffs. Reviewers comment directly on the rendered lesson, their feedback is applied, and every change is logged, which made review rounds faster and easier to track.

  3. Diagram pipelineAI + scripts

    Built a system that generates draft maths diagrams from a written description and uploads them, ready to drop into lessons for checking and polishing.

  4. Accuracy safeguardsHuman + automated

    Every AI draft goes through validation scripts (answer-key generation, lesson checks) and human review against the curriculum and house style. My lead described my approach as using LLM tools as “force multipliers for the high standard she already holds herself to.”

  5. Everyday useClaude, OpenAI, Grok

    Drafting and rewording, checking answers, researching curriculum documents, and summarising feedback and project history from tools like ClickUp and Slack.

Process

How I run a project

Scope first

Every book starts from its curriculum source: what each lesson covers, what students already know, and where the boundaries sit. That keeps writers aligned before a word is written.

One house style

I set notation and style decisions once, record them, and apply them book-wide, so a team of writers produces content that reads as one voice.

Review in rounds

Chapters move through authoring, review and edits with clear hand-offs in ClickUp. Reviewer comments are applied and logged, so nothing is lost between rounds.

Accuracy checks

Proofing and mechanical reviews, answer-key checks and validation scripts catch errors before students see them.

Train the team

I write guidelines, train new builders and writers, and stay available as the person they can ask.

AI built in

AI drafts, checks and summarises at each stage, from first chapter drafts to applying review feedback, with a person signing off before anything ships.

House style

Examples of style decisions

A few of the book-wide conventions I set for the UK textbooks, each checked against DfE guidance and UK exam practice.

TopicDecision
Recurring decimalsDot notation on the first and last repeating digits, matching UK convention
VectorsBold for named vectors, an arrow over two letters for vectors between points
TerminologyUK terms throughout, such as “cuboid” and “positive skew”
Answer keysFull stops only on full sentences, so short answers read cleanly
Prior knowledgeLinks to earlier lessons only in the lesson introduction, with titles matching the source exactly
